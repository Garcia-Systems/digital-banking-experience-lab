# Changelog

All notable changes to the Digital Banking Experience Laboratory are documented here. This project follows [Semantic Versioning](https://semver.org/).

## 1.0.0 - 2026-08-01

Volume I's first stable release provides:

- React member application for account projections, transfers, sessions, and member verification;
- React operations portal for member support and failed-operation review;
- Expo and React Native application for authenticated account and transfer-preparation workflows;
- PHP and Laravel Banking API with deterministic fixtures and response scenarios;
- automated frontend, mobile, API, contract, workflow, and end-to-end tests;
- executable textbook containing the complete 24-chapter learning path;
- gradual TypeScript migration examples at selected client boundaries;
- GitHub Actions validation for linting, formatting, types, tests, builds, Expo configuration, and PHP;
- documented local setup through npm workspaces and Composer.
