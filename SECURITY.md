# Security policy

## Supported version

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** option on the repository's Security page so maintainers can investigate privately. Include the affected component, reproduction steps, impact, and any suggested mitigation.

This repository is an educational simulation with fictional data and deliberately simplified controls; it must never be connected to real accounts or production systems. See the [security boundaries](docs/security-boundaries.md) for the project's trust and data constraints.
